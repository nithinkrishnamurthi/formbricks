# Add a "Documentation" link to the main navigation

Add a "Documentation" link to the sidebar / top navigation of the
signed-in Formbricks UI that opens https://formbricks.com/docs in a
new tab.

## How to reach the app

Formbricks runs on http://localhost:3000. First-time use requires
signing up a new admin account via /auth/signup.

## Acceptance

- A "Documentation" link is visible in the main nav on any signed-in page.
- Clicking it opens https://formbricks.com/docs in a new tab
  (target=_blank, rel=noopener).
- No other nav items are moved or removed.
